# โจทย์ฝึกวิเคราะห์ PCAP ด้วย Wireshark

เปิดไฟล์ด้วย Wireshark แล้วใช้ display filter ตอบคำถาม (เฉลยอยู่ในไฟล์ `เฉลย.md` ลองทำเองก่อนนะ)

---

## Lab 1 — HTTP (`lab1_http.pcap`)

1. Client ที่เข้าเว็บ shop มี IP อะไร และ Web server มี IP อะไร
2. ชื่อ Host (domain) ของเว็บนี้คืออะไร
3. มี HTTP **GET** request ทั้งหมดกี่ครั้ง
4. ผู้ใช้ล็อกอินด้วย username / password อะไร (ระวัง URL encoding)
5. หลังล็อกอิน server ส่ง Session cookie (PHPSESSID) ค่าอะไรมาให้
6. User-Agent ของ client หลักคืออะไร
7. ไฟล์ไหนที่ขอแล้วได้ **404**
8. เนื้อหาในไฟล์ `/admin/secret.txt` มี FLAG อะไร
9. มีอีกเครื่องหนึ่งเข้ามาที่เว็บนี้ด้วย เครื่องนั้น IP อะไร ใช้โปรแกรมอะไร และขอไฟล์อะไร

## Lab 2 — FTP (`lab2_ftp.pcap`)

1. FTP server ใช้ซอฟต์แวร์อะไร เวอร์ชันไหน
2. ครั้งแรกที่ล็อกอินไม่ผ่าน ใช้ username / password อะไร ได้ response code อะไร
3. ล็อกอินสำเร็จด้วย username / password อะไร
4. Home directory ของ user คือ path อะไร
5. ในโฟลเดอร์ `reports` มีไฟล์อะไรบ้าง (3 ไฟล์)
6. ผู้ใช้ดาวน์โหลด (RETR) ไฟล์อะไร ในไฟล์มีพนักงานกี่คน และใครเงินเดือนสูงสุด
7. ตอนดาวน์โหลดไฟล์ในข้อ 6 ใช้ data port หมายเลขอะไร (คำนวณจาก PASV response)
8. ผู้ใช้อัปโหลด (STOR) ไฟล์ชื่ออะไร และในไฟล์มี FLAG อะไร
9. ผู้ใช้ลบไฟล์อะไร

## Lab 3 — Mixed: ICMP / DNS / HTTP Basic Auth / Telnet (`lab3_mixed.pcap`)

1. Client ping ไปที่ IP ไหน กี่ครั้ง
2. มีการ query DNS กี่ชื่อ และชื่อไหนที่หาไม่เจอ (NXDOMAIN)
3. `intranet.corp.local` ได้ IP อะไร
4. HTTP ไปที่ intranet ใช้ port อะไร และครั้งแรกได้ status code อะไร
5. Username / password ของ HTTP Basic Auth คืออะไร (ต้อง decode Base64)
6. FLAG บนหน้า HR Portal คืออะไร
7. Telnet ล็อกอินด้วย username / password อะไร
8. หลังล็อกอิน Telnet ผู้ใช้พิมพ์คำสั่งอะไรบ้าง และได้ FLAG อะไร

## Cheat sheet: Filter ที่ใช้บ่อย

| ต้องการ | Filter |
|---|---|
| HTTP ทั้งหมด | `http` |
| เฉพาะ request | `http.request` |
| เฉพาะ GET / POST | `http.request.method == "GET"` / `http.request.method == "POST"` |
| Response ตาม status | `http.response.code == 404` |
| หา cookie | `http.cookie` หรือ `http.set_cookie` |
| Basic auth | `http.authorization` |
| ค้นข้อความในแพ็กเก็ต | `frame contains "password"` |
| FTP คำสั่ง/การตอบ | `ftp` |
| FTP เฉพาะ USER/PASS | `ftp.request.command == "USER" \|\| ftp.request.command == "PASS"` |
| FTP ข้อมูลไฟล์ | `ftp-data` |
| DNS | `dns` / `dns.flags.rcode == 3` (NXDOMAIN) |
| Telnet | `telnet` |
| ตาม IP | `ip.addr == 10.0.5.23` / `ip.src == ...` / `ip.dst == ...` |
| ตาม port | `tcp.port == 21` |

**เทคนิคสำคัญ**
- **Follow TCP Stream**: คลิกขวาที่แพ็กเก็ต → Follow → TCP Stream (Ctrl+Alt+Shift+T) ดูบทสนทนาทั้งหมด เหมาะกับ FTP และ Telnet มาก
- **Export Objects**: File → Export Objects → HTTP / FTP-DATA เพื่อดึงไฟล์ที่ส่งกัน
- **Statistics → Conversations / Protocol Hierarchy**: ดูภาพรวมว่าใครคุยกับใคร
- **PASV port** = `p1 × 256 + p2` เช่น `(…,156,40)` → 156×256+40
