# โจทย์ถอดรหัส TLS (ต้องหา key ในไฟล์ก่อน)

สถานการณ์: ข้อมูลสำคัญถูกส่งผ่าน HTTPS ซึ่งเข้ารหัสอยู่ แต่ในไฟล์ pcap เดียวกันมีจุดที่ key รั่วออกมา
ให้หา key นั้นให้เจอก่อน แล้วนำไปใส่ใน Wireshark เพื่ออ่านข้อมูลที่เข้ารหัสไว้

> ถ้าทำไม่ได้ เฉลยแบบสอนทีละขั้นอยู่ที่ `เฉลย_TLS.md`

---

## Lab 4 — TLS 1.3 + Key Log File (`lab4_tls_keylog.pcap`)

**ส่วน A: ก่อนถอดรหัส**
1. Client เชื่อมต่อ HTTPS ไปที่ IP อะไร และ SNI (ชื่อเว็บใน Client Hello) คืออะไร
2. Session นี้ใช้ TLS เวอร์ชันไหน และ cipher suite อะไร (ดูจาก Server Hello)
3. ลองใช้ filter `http` ตอนนี้ เห็นข้อมูลของ HTTPS ไหม เพราะอะไร

**ส่วน B: หา key**

4. ใน pcap นี้ยังมีโปรโตคอลอื่นที่ไม่ได้เข้ารหัส คือโปรโตคอลอะไร และล็อกอินด้วย user / pass อะไร
5. มีไฟล์ถูกส่งชื่ออะไร ไฟล์นี้ encode ไว้ด้วยวิธีไหน
6. Decode ไฟล์นั้นแล้วจะได้อะไร บรรทัดในไฟล์ขึ้นต้นด้วยคำว่าอะไรบ้าง

**ส่วน C: ถอดรหัส**

7. นำ key ไปใส่ใน Wireshark แล้ว filter `http` ตอนนี้เห็น request อะไรบ้าง
8. ผู้ใช้ล็อกอินเว็บด้วย username / password อะไร
9. Cookie `sid` มีค่าอะไร
10. FLAG ในไฟล์ `/files/flag.txt` คืออะไร

## Lab 5 — TLS 1.2 + RSA Private Key (`lab5_tls_rsa.pcap`)

**ส่วน A: ก่อนถอดรหัส**
1. ไฟล์นี้มี HTTPS ไปเว็บไหน (SNI)
2. Cipher suite ที่ตกลงกันคืออะไร การแลกเปลี่ยน key ใช้วิธีไหน (RSA หรือ ECDHE)
3. Certificate ของ server ออกให้ชื่อ (CN) อะไร

**ส่วน B: หา key**

4. ก่อนเข้าเว็บธนาคาร client ไปดาวน์โหลดอะไรจากเครื่องไหน (ดู HTTP ที่ไม่เข้ารหัส)
5. ใน zip มีไฟล์อะไรบ้าง ไฟล์ไหนคือ key ที่ต้องใช้
6. จะรู้ได้อย่างไรว่า key นี้ตรงกับ certificate ของเว็บธนาคาร (ตอบเป็นแนวคิด)

**ส่วน C: ถอดรหัส**

7. ผู้ใช้ทำรายการอะไรบนเว็บ (ดู POST)
8. เลขบัญชีต้นทาง, PIN, บัญชีปลายทาง และจำนวนเงินคืออะไร
9. เลขอ้างอิง (Ref) ของรายการ และ FLAG คืออะไร

**คำถามเชิงทฤษฎี**

10. ทำไม private key ถึงใช้ถอด Lab 5 ได้ แต่ใช้ถอด Lab 4 (TLS 1.3) ไม่ได้
11. ถ้าเว็บใช้ ECDHE แต่เรามีแค่ private key ของ server จะถอดรหัสได้ไหม
